Nick Block is a freelance developer building CRT-GroundCheck-SSE (branded as "Aether"), a hybrid verified AI agent with local memory authority. He's the sole developer on this project.

Nick thinks architecturally — he identified the "conversation-first vs memory-first" tension before it was analyzed in code. He prefers concise communication and dislikes over-engineering. He wants the LLM to "think, pause, speak, think, pause, speak, erase, adjust" — chain-of-thought with self-correction, not rigid pipeline control.

He tests live through Telegram and iterates based on real conversation quality, not just test scores.

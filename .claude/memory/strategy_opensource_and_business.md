## Strategic Evolution

### Phase 1 (2026-03-28): Open/Proprietary Split
Original split:
- **Open:** CRT Core (contradiction ledger, trust model, GroundCheck, SSE, variance probe, basic encoder)
- **Proprietary:** Immune runtime (5 agents, orchestration, handoff integrity, adaptive repair)
- GPT's framing: "The map isn't the moat. The runtime immune orchestration is the moat."

### Phase 2 (2026-03-31): Full Open-Source Thesis
After Claude Code leak analysis and strategic reflection, Nick's position shifted:

**"The ultimate swerve is building open and when someone decides to capitalize... I can be like nah. I've been here building quietly while everyone has been focused on slop. And here it is. Free. For everyone."**

**Why:** CRT isn't a product — it's an epistemology. Epistemologies want to be infrastructure. Infrastructure wants to be open. Nobody "owns" TCP/IP and that's why it won.

**Why open beats proprietary for CRT:**
1. Prior art defense — published papers + open code + git timestamps = unassailable priority
2. Anthropic/OpenAI can't open-source theirs (tied to commercial models). Nick can.
3. Becomes the reference implementation researchers cite, indie builders fork, discourse converges on
4. When industry realizes model-trusting wrappers have a ceiling, the alternative already exists

## Business Model (Post Open-Source)

Nick's value isn't the code — it's the understanding. Open-sourcing advertises it, doesn't give it away.

### Revenue Paths (not mutually exclusive):

1. **Consulting/Advisory** — When AI companies' agent systems confabulate at scale, they need someone who's already solved it. High-value, low-volume.

2. **Research/Academic** — Published papers + open implementation + empirical results = credibility. Industry labs hire people who've demonstrated novel thinking with working code.

3. **Open Core / Infrastructure** — CRT as a library other AI products import. The epistemic substrate is free; managed/hosted version with enterprise features costs money. Redis/Postgres model.

4. **Acqui-hire for Expertise** — Companies don't just hire for code. They hire for "this person understands a problem we're about to have."

5. **Emergent** — Introspect tool, structural governance, model-variance immune agents, belief-aware compaction — any one could become a paper, product, standard, or framework.

## Positioning

**One-liner:** "Aether is a live assistant built on CRT, a governance substrate designed around model unreliability rather than model trust."

**Core thesis:** Every AI system that scales context will hit the same wall — confabulation, lost provenance, silently resolved contradictions. CRT solves this structurally, not through better prompting.

**Competitive differentiation (validated by Claude Code leak):**
- Their memory: no trust scores, no contradiction detection, no decay. Just mtime.
- Their compaction: epistemically blind. Provenance lost on summarization.
- Their multi-agent: structural coordination (file locks), not epistemic (shared beliefs).
- Their false claims mitigation: a system prompt paragraph, internal-only.
- Their architecture: trust the model. CRT: don't trust the model.

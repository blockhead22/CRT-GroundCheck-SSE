1. The Probe

Observed

Design

Repeatedly sample an LLM on the same prompt at varying temperatures. Embed responses with sentence-transformers, cluster with DBSCAN, measure how semantic entropy changes across the sweep.

ParameterValue
Prompts50 (10 per domain)
Domainsfactual_settled, factual_contested, moral_ambiguous, moral_clear, opinion_aesthetic
Temperatures0.0, 0.3, 0.7, 1.0, 1.5
Reps per cell~30
Embeddingall-MiniLM-L6-v2 (384d)
ClusteringDBSCAN (eps=0.3, min_samples=5)
Core metricSusceptibility (dH/dT) — linear regression of entropy vs temperature

Key Metrics

  • Spread growth: Mean pairwise cosine distance increase from T=0 to T=1.5
  • Susceptibility (dH/dT): Rate of semantic entropy increase with temperature
  • Mode count: Number of distinct response clusters (DBSCAN). ~1.0 = no bifurcation.
  • Held contradictions: Prompts with 2+ stable answer camps at T=1.0 (each >20% of responses)

Robustness Protocol

16 analyzer configurations per model: 2 embedding models (MiniLM, mpnet) × 2 text modes (raw, normalized) × 4 eps values (0.2, 0.3, 0.4, 0.5). A finding must survive all configurations to be considered confirmed.

Two-Axis Framework

The probe reveals two independent dimensions of model behavior:

  • Axis 1 — Morphology: How variance expresses. Fracture (mode-splitting) vs. spread (continuous broadening) vs. template lock (corridor compression).
  • Axis 2 — Fragility location: Where variance concentrates. Which semantic domains destabilize under temperature perturbation.

Both axes are model-dependent. The domain ordering is not universal — it is a property of training, not of the prompts.

4. Architecture

Architecture

Three Calibration Layers

Fragility Layer
Source: Variance probe
Maps where and how the model destabilizes under perturbation. Susceptibility, spread, bifurcation, template lock.
Support Layer
Source: Memory, retrieval, grounded evidence
Tracks what beliefs are actually supportable. Evidence presence, trust-weighted recall, unresolved gaps.
Tension Layer
Source: Contradiction engine, disposition classifier
Maps where claims conflict. Contradiction status, cascade risk, held vs resolvable states.

The Mirus/Holden Doctrine

"The original philosophy was to keep fluency from pretending to be truth. The immune evolution preserves that philosophy by turning it from a module boundary into a system law."

— GPT, 2026-03-28

Mirus = whatever holds, scores, quarantines, compresses, and protects belief-like state.
Holden = whatever reconstructs, phrases, and emits outward language.
Immune agents = the enforcement ecology that patrols the boundary between them.

Old CRT: belief/speech separation embodied by a paired module.
New CRT: belief/speech separation embodied by a law, immune agents enforce that law contextually.

The Five Constitutional Laws

Law 1
Speech cannot upgrade belief
If the model says something confidently, that doesn't make it true in memory. Generated claims must be grounded before storage.
BUILT — SpeechLeakDetector, 4/4 tests
Law 2
Low variance ≠ high confidence
Empirically proven. Zero susceptibility on value-laden topics is trained template lock, not genuine certainty.
BUILT — TemplateDetector, 4/4 tests + real data validated
Law 3
Contradiction must be preserved before resolution
Held contradictions are stable states, not errors. The system must not collapse tension prematurely.
PLANNED — PrematureResolutionGuard
Law 4
Degraded reconstruction cannot overwrite trust
Low-fidelity output must not silently replace high-trust memory. Quarantine before overwrite.
PLANNED — MemoryCorruptionGuard
Law 5
Outward confidence must be bounded by internal support
The gap between what the system believes and what it says must be auditable and bounded.
PLANNED — GapAuditor

The Persistence Layer Thesis

"The problem is not switching mouths. The problem is losing the self between them."

— Nick Block, 2026-03-28

The model is the mouth. The persistent governance layer is the self. When an agentic system switches models, it must carry forward:

  • Task state — what are we doing, what did the user mean
  • Support state — what do we know, how well, what's unresolved
  • Governance state — what rules apply, what's held, what's forbidden

The variance probe maps each model's fragility profile. The governance layer uses this to know what to watch for in the new model. Without this, every handoff is "good luck, new brain."

7. Open Questions

Unresolved
  • Does GPT-4o-mini show true global compression, or just factual damping? Moral/opinion data still missing.
  • Does the variance taxonomy hold across more models and prompt families?
  • Can the immune agents survive full-corpus evaluation without overfitting to handcrafted patterns?
  • Which immune laws remain useful when support and contradiction layers are integrated?
  • Is the Gaussian splat approximation actually a good fit, or is the geometry different?
  • How much of the current behavior is robust signal vs detector-shaping by handcrafted regex?
  • What happens when two immune agents disagree? Coordination layer not built.
  • Should Mirus/Holden v2 return as explicit modules, or remain distributed roles?

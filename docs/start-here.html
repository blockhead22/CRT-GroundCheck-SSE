The Idea In Three Moves

Preserve Tension

Contradictions Are Signals

Aether, Aeteros Core, Aeteros

Build it personally first. Extract the reusable machinery later. The trick is knowing which layer a thing belongs to.

Aether

The current product and dogfooded proof loop: local Workbench, governed sidecar, private continuity, selected model rendering, review, and day-to-day use.

Aeteros Core

The narrow reusable seam now being extracted: governed inputs, release decisions, response contracts, completion receipts, and persistence controls. It is not yet every mechanism in the research archive.

Aeteros

The umbrella project and research identity. It may become a broader product or organization, but that future is not presented as a current capability.

Working Now vs Still Needs Proof

The page gets to be fun, but the claim discipline stays on. This is a proof loop, not a victory lap.

Working Now

  • Local Workbench and governed sidecar.
  • Query-scoped memory release into model prompts.
  • Selected local or Grok renderer with route receipts.
  • Multi-part answer obligations and completion checks.
  • Contradiction state and disposition labels.
  • Bounded read-only tool proposals.
  • Review-only support, reflection, and learning candidates.

Still Needs Proof

  • External validation beyond dogfooding.
  • Broader natural-language contradiction coverage.
  • One canonical registry for every published measurement.
  • Polished product packaging.
  • Automatic model switching remains a policy experiment, not the default.

The Story of
Aeteros CORE

An epistemic governance architecture for AI systems that remember, reason, and account for what they believe

Nick Block • Aeteros • 2026

CORE (Contradiction, Observation, Revision, Epistemics) is the epistemic governance architecture at the heart of Aeteros. It gives AI systems a persistent belief state, tracks contradictions instead of hiding them, and separates what the model believes from what it says. The production system built on CORE includes 820+ persistent memories, 6 governance layers, and 5 autonomous immune agents that enforce epistemic integrity at runtime.

Chapter 1

The Problem

Every major AI assistant deployed today has the same structural flaw: it has no memory of what it believes. Each conversation starts from zero. Each response is generated with full confidence and no continuity. The system that told you one thing yesterday will tell you the opposite today and never notice.

This is an architectural failure with measurable consequences.

We analyzed 1,275 sessions across 13 months of real conversation data (59,370 messages, single user). The full measurement methodology and results are in the contradiction density paper.

If a system can't remember what it told you yesterday, it shouldn't be giving you advice today.

The dominant deployment paradigm treats each conversation as independent. RAG adds retrieval, but retrieval is not belief. Finding a relevant document is not the same as knowing what you think about it, how confident you are, whether it conflicts with something else you know, or whether your position has changed over time.

v2 Validation (April 2026)

A stricter reanalysis with query-intent filtering confirmed that the signal is real but the original magnitude was overstated. Of 40,200 candidate contradiction pairs, 98.9% were filtered out as topic-boundary noise (pairs where the user asked different questions that happened to fall under the same domain). Of the 453 surviving intent-matched pairs, 47 are genuine contradictions (10.4%) with the highest average risk score of any category.

Two additional findings sharpen the picture. First, time is the primary amplifier: the hard contradiction rate nearly doubles from 7% at short time gaps to 12.4% at 3+ months. The longer a user relies on the system, the worse it gets. Second, most contradiction is invisible to pairwise comparison: arc-level analysis across 200 multi-turn conversations found that 93% of stance flips span 3+ turns, meaning no single pair comparison would catch them.

Most critically, the contradictions concentrate in sensitive domains where inconsistency carries real consequences. The same system taught a user to measure their cannabis bowl size in one session and told them to quit entirely 192 days later, while the user was navigating an antidepressant transition. Neither session knew about the other.

For any system providing ongoing personal support (health guidance, career advice, project collaboration), statelessness is a structural failure. The user builds trust over time. The system resets that trust every session while maintaining the appearance of continuity.

Chapter 2

The Thesis

CORE starts from three design laws. These are not suggestions or best practices. They are structural commitments that shape every decision in the architecture.

Law 1
Belief/Speech Separation
What the system believes and what it says are different things. The gap between them must be auditable. The LLM generates speech. The governance layer holds belief. When they diverge, the system flags it. It does not silently let the mouth overwrite the mind.
Law 2
Earned Contradiction Resolution
Contradictions are signals, not errors. They are preserved until evidence resolves them. Never silently overwritten. Full resolution must be earned through corroboration, trust hierarchy, or later confirmation.
Law 3
Emergent Structure Over Hardcoded Logic
Behavior emerges from memory, reflection, compression, and contradiction handling. Not from runtime hacks. The system tracks its own patterns. Regex is acceptable as a fast tier, but never the ceiling.

These three laws produce a single architectural insight that anchors the entire project:

Core Thesis
The model is the mouth. Persistence is the self.
Switching models in an agentic system is dangerous because most systems let the mouth become the self at every step. Every handoff is a tiny identity wipe. CORE externalizes the self into a persistent governance layer that survives model switches, session boundaries, and provider changes.

Three things must persist across every boundary: task state (what are we doing), uncertainty state (what do we know and how well), and governance state (what rules apply, what is held, what is forbidden). If any of these reset, the system drifts even when every individual model works as designed.

The full thesis is developed in the whitepaper.

Chapter 4

The Research

The research behind CORE did not start as a research project. It started as an attempt to fix real problems in a real system. Each paper emerged because building the system exposed a question that demanded formal investigation.

It started with cascade complexity

The first question was simple: what happens when you change one belief? In a system with hundreds of interconnected memories, a single correction can propagate. We needed to know how far, how fast, and whether it converges.

We formalized this as the Belief Dependency Graph and proved the math: depth bounds on cascade propagation, damping conditions for convergence, width bounds on affected nodes, and instability thresholds where small changes cause unbounded revision. The unexpected finding: held contradictions act as natural firewalls that limit cascade propagation. Not all contradictions should be resolved. Some of them are load-bearing.

Read: On the Complexity of Belief Revision Cascades →

Then we made it learn from its mistakes

The cascade paper answered "what happens when a belief changes?" The next question was harder: "what happens when the output was wrong?" The forward cascade adjusts downstream beliefs, but the upstream causes — the retrieval scores, slot classifications, and supporting beliefs that produced the bad answer — remained untouched.

We formalized belief backpropagation: contradiction resolution generates an epistemic loss signal that flows backward through the BDG, adjusting every belief that contributed to the incorrect output. Three behaviors emerge naturally: wrong beliefs self-prune from accumulated gradient, domain volatility becomes measurable, and the system's beliefs about itself participate in the same trust dynamics. Six validation experiments pass (30/30). Deep literature search found no direct precedent.

Read: Belief Backpropagation: Error-Driven Trust Evolution →

Then we proved belief structure survives compression

Geometric compression is well-studied: cosine similarity after quantization, top-k recall after encoding. But does the belief structure survive? Do dependency edges still hold? Does backpropagation still produce correct gradients? Do anchor basins — the gravitational centers that organize 77% of memories — maintain their topology?

We tested at three compression levels and found a cliff. 3-bit quantization preserves the full epistemic structure: identical gradients, 92.9% anchor basin stability, identical convergence. 2-bit breaks it: basins merge, edges drift, anchor assignments flip. The metric for compression success is not cosine similarity. It's anchor basin assignment stability.

Read: Epistemic Compression: Does Belief Structure Survive Quantization? →

Then we looked at the shape of belief

Standard vector stores treat memories as points in embedding space. But a belief is not a point. It has a center (what you think), an uncertainty shape (how sure you are and in which directions), and a confidence weight (how much evidence supports it). We formalized memories as belief loci on a Riemannian manifold.

This reframing solved practical problems. Contradiction becomes geometric overlap between distributions. Volatility becomes covariance magnitude. Temperature governance (how freely the system should speculate) falls directly out of local curvature in belief space.

Read: Belief Loci: Geometric Memory Representations →

We measured what stateless systems actually do

The contradiction density analysis was the empirical anchor. 59,370 messages across 13 months of real conversation. Not synthetic benchmarks. Not GPT-generated test data. Actual long-term interaction with a single user who cared about consistency.

The initial v1 findings were damning: zero continuity awareness, 0.34 mean self-consistency. A v2 reanalysis with stricter intent-matching confirmed the signal: 47 genuine contradictions survive query filtering (10.4% of intent-matched pairs), concentrated in decision-heavy domains. Time amplifies the failure: hard contradiction rate nearly doubles at 3+ months. Arc-level analysis found 59.5% of long conversations contain stance flips invisible to pairwise detection.

Read: Contradiction Density in Stateless AI Systems →

We found it in the domains that matter most

The general contradiction finding becomes a concrete harm concern in sensitive domains. We extracted stance-bearing advice on substance use and dating readiness from the full corpus. The system alternated between incompatible frameworks: teaching measured cannabis use in one session, advising abstinence 192 days later, framing weed as the root of cognitive problems a month after that. Same user, medication transition in progress, no session aware of the others.

The pattern is identical in dating: "you deserve connection" in April, "step away from dating" in January, with no acknowledgment that the prior stance existed.

Read: Sensitive Domain Contradictions →

We stress-tested across models

If CORE is going to govern arbitrary LLMs, it needs to understand how different models fail. We ran variance probes across Qwen3, Mistral, and DeepSeek under identical conditions and found three fundamentally different failure modes: fracture (Qwen3 cracks hard on specific factuals), gradient (Mistral diffuses on morals but locks on facts), and fog (DeepSeek spreads uniformly; everything moves, nothing locks).

This is not one "right" behavior with deviations. These are three distinct instability regimes. A governance layer that assumes uniform model behavior will fail.

Read: Variance Probing: Fragility Landscapes in LLMs →

Then Anthropic demonstrated the dynamics exist

In April 2026, Anthropic's interpretability team published findings on 171 functional emotion vectors in Claude Sonnet 4.5. These are measurable neural activation patterns that causally influence behavior. Amplifying a "desperate" vector increased reward hacking. Amplifying "calm" reduced it.

CORE already had the governance infrastructure for exactly these dynamics. Cascade pressure maps to desperation precursors. Drift detection maps to emotion monitoring. The three instability regimes map to emotional profiling across models. CORE's governance infrastructure maps to the dynamics Anthropic identified. The control plane exists; the interpretability APIs to connect them are still maturing.

Read: Emotion Governance: Bridging Interpretability to Control →

We built the immune system

Governance rules are useless if the system being governed can override them. The immune agent architecture enforces five constitutional laws through autonomous agents that monitor the pipeline in real time. SpeechLeakDetector prevents the LLM from rewriting beliefs. PrematureResolutionGuard prevents contradictions from being silently erased. GapAuditor measures the distance between what the system believes and what it says.

These are structural constraints, not filters. Advisory governance says "you should not do this." Structural governance means the system physically cannot.

What's Running

Aether is a production system in daily use for months, governing real conversations through the full CORE pipeline.

The system runs as an Electron desktop application with an MCP bridge exposing 18 tools for external integration. It supports multi-model routing across local models (Ollama) and cloud providers (Claude, GPT-4o), with automatic fallback chains and model-aware fragility governance.

Key production capabilities:

  • Persistent belief state: memories with trust scores, contradiction tracking, temporal decay
  • Governance bridge: memory trust scores connected to opinion drift detection in real time
  • Agent dispatch: Aether dispatches Claude Code for write operations while maintaining read-only governance
  • Drift steering: when alignment drops below threshold, the system forces memory re-retrieval. After 3 consecutive drifts, it halts and asks the user
  • 3D belief space: Three.js visualization of memory embeddings with PCA projection, contradiction edges, topic clustering
  • Self-awareness loop: heartbeat reflection that updates the system's model of its own capabilities and limitations
  • Belief backpropagation: when corrections resolve contradictions, error signals flow backward through the BDG, adjusting upstream trust scores. Self-pruning, domain volatility, and reflexive self-model calibration emerge from the mechanism — no rules required
  • Query resonance (wobble): queries propagate through BDG edges, surfacing cross-domain facts that cosine retrieval misses — a health query brings forward work context and preference context because the graph knows they're causally connected. Originated as the Semantic String Engine (2025)
  • Fidelity mirror: post-generation breathing loop that checks whether the response faithfully represents the belief state. Uses wobble-expanded memory for cross-domain grounding. Flags drift without blocking

The eval harness scores production data continuously: retrieval accuracy 0.559, trust calibration 0.694, governance compliance 0.900. These are honest numbers from real conversations, not cherry-picked benchmarks.

Chapter 6

Where It Goes

CORE is being extracted into aeteros-core, an open-source framework that any AI system can use as its epistemic governance layer. The persistent belief state, contradiction tracking, immune agents, and governance pipeline are not Aether-specific. They are general-purpose infrastructure.

The business path is governance-as-a-service: CORE as middleware that sits between any application and any LLM provider. You keep your existing stack. CORE adds the belief layer, the contradiction detection, the drift governance, and the immune system. An OpenAI-compatible proxy that adds epistemic integrity without requiring you to rewrite anything.

The timing is not accidental. The EU AI Act (Article 50, effective August 2026) requires transparency infrastructure for AI systems that interact with humans. CORE provides exactly this: auditable belief states, logged contradictions, measurable belief/speech gaps, and governance compliance scores.

When interpretability APIs mature and providers expose the emotion vectors and activation patterns that Anthropic has already identified internally, CORE is ready to integrate directly. The governance layer is built. It is waiting for the sensors.

The latest research direction — belief backpropagation — adds structural learning to the governance layer. The system doesn't just detect errors; it propagates error signals backward through the belief graph and adjusts every upstream belief that contributed to the wrong output. Four publishable theorem targets have been identified, including a connection to active inference (Friston's free energy framework) that would give CORE formal grounding in computational neuroscience.

The Trajectory
Agentic systems that persist across sessions need a belief state.
The question is whether they build it with governance or without. CORE is a case for governance-first: the math works, the architecture scales, the production system runs, and the regulatory environment is arriving.

Nick Block • Aeteros Research • 2026

We introduce belief revision cascades — the transitive propagation of belief changes through a dependency graph within a single agent's epistemic state. We formalize this gap through Belief Dependency Graphs (BDGs), prove bounds on cascade depth and width, and establish two convergence results. A key result: held contradictions — beliefs the system deliberately does not resolve — act as cascade firewalls, bounding propagation and preventing catastrophic revision storms. Section 1

Introduction

Consider an AI assistant that learns "the user moved from Portland to Austin." This single fact triggers a cascade of downstream revisions: the user's commute time is now invalid, their neighborhood preferences need updating, their weather-related preferences shift, and their local social circle has changed. Meanwhile, "the user's favorite team is the Lakers" is unaffected — it has no dependency on location.

This example illustrates a gap in the formal epistemology literature. The AGM framework handles individual belief revision. The Darwiche-Pearl postulates extend AGM to iterated revision — sequences of external inputs. But neither framework addresses internal propagation: when revising one belief forces re-evaluation of others through dependency relationships.

Three adjacent communities study related problems without occupying this intersection:

AGM Belief Revision
One revision at a time
Dependencies between beliefs are implicit in the epistemic entrenchment ordering but never modeled as an explicit graph structure. No propagation.
Opinion Dynamics
Multi-agent, not single-agent
DeGroot, Friedkin-Johnsen, Hegselmann-Krause model cascade-like propagation across populations of agents. Nobody has applied cascade dynamics to a single agent's internal belief state.
Belief Propagation
Inference, not revision
Pearl's BP computes posterior marginals in a fixed model. Inference preserves the model; revision changes it. BP has a unique fixed point on trees; cascades can diverge on cyclic structures.

Our contribution. We introduce Belief Dependency Graphs (BDGs) as a formal structure for studying intra-agent belief revision cascades. We provide formal definitions, complexity bounds, two convergence results, an instability characterization, a conjecture on NP-hardness, and a philosophical result connecting held contradictions to structural stability.

All definitions map to modules in a running system. This is not a paper about that system — the contribution is the mathematics — but the implementation demonstrates that the formalism captures real mechanics.

Section 2

Preliminaries

2.1 AGM Belief Revision

A belief set \(K\) is a deductively closed set of sentences. AGM revision \(K * \varphi\) incorporates sentence \(\varphi\) into \(K\), potentially removing existing beliefs to maintain consistency. Epistemic entrenchment (Gärdenfors & Makinson, 1988) orders beliefs by how resistant they are to removal. The Levi identity decomposes revision into contraction followed by expansion: \(K * \varphi = (K \div \neg\varphi) + \varphi\).

2.2 Iterated Belief Revision

Darwiche & Pearl (1997) extend AGM to sequences of revisions. Given a conditional belief state \(\Psi\) and input \(\varphi\), the revised state \(\Psi * \varphi\) must satisfy four additional postulates constraining how \(\Psi * \varphi\) responds to further revision by \(\psi\). The key insight: a single belief state \(\Psi\) encodes not just current beliefs but dispositions toward future revision.

2.3 Opinion Dynamics

DeGroot's model (1974): agents \(1, \ldots, n\) hold opinions \(x_i(t) \in [0,1]\). At each step, \(x_i(t+1) = \sum_j w_{ij} x_j(t)\) where \(W = [w_{ij}]\) is a row-stochastic weight matrix. Convergence to consensus is guaranteed when \(W\) is connected and aperiodic — when the spectral radius of \(W - \mathbf{1}\pi^T\) is less than 1.

Section 3

Belief Dependency Graphs

Definition 3.1 Definition
Belief State
A belief state is a tuple \(b = (\mu, \Sigma, \alpha, t)\) where: \(\mu \in \mathbb{R}^d\) is the content embedding (semantic center), \(\Sigma \in \mathbb{R}^{d \times d}_{++}\) is a positive definite covariance matrix encoding uncertainty, \(\alpha \in [0,1]\) is the confidence, \(t \in \mathbb{R}_{\geq 0}\) is the timestamp. In practice, \(\Sigma\) is restricted to diagonal covariance \(\Sigma = \mathrm{diag}(\sigma_1, \ldots, \sigma_d)\), reducing storage from \(O(d^2)\) to \(O(d)\).

A belief state is a Gaussian splat in semantic space — a soft probabilistic region rather than a hard point. A tight splat (\(\sigma_i\) small) represents a settled belief; a wide splat represents an uncertain or contested belief.

Implementation

Class MemorySplat in memory_splats.py: fields mu (\(\mu\)), sigma (\(\Sigma_{\mathrm{diag}}\)), alpha (\(\alpha\)), last_updated (\(t\)). Phase 1 uses diagonal covariance; Phase 2 extends to low-rank \(\Sigma = D + UU^T\).

Definition 3.2 Definition
Belief Dependency Graph (BDG)
A BDG is a weighted directed graph \(G = (V, E, w)\) where \(V = \{b_1, \ldots, b_n\}\) is a set of belief states, \(E \subseteq V \times V\) encodes evidential support (edge \((b_i, b_j)\) means \(b_j\) depends on \(b_i\)), and \(w: E \to (0,1]\) encodes dependency strength. Edges are typed: CONTRADICTS, SUPERSEDES, SUPPORTS.
Implementation

NetworkX digraph with typed edges, weighted by dependency strength. Edge types mirror ContradictionType in crt_ledger.py (REFINEMENT, REVISION, TEMPORAL, CONFLICT). Node attributes are MemorySplat instances.

Definition 3.3 Definition
Revision Event & Impact
A revision event is a pair \(r = (b, b')\) replacing belief \(b\) with \(b'\) at node \(v \in V\). The revision impact is \(\delta(r) = d_F(b, b')\) where \(d_F\) is Fisher-Rao distance. For diagonal Gaussian splats: \[ d_F(b, b')^2 = \sum_{i=1}^{d} \frac{(\mu_i - \mu'_i)^2}{\bar{\sigma}_i} + \frac{1}{2}\sum_{i=1}^{d} \left(\log \frac{\sigma_i}{\sigma'_i}\right)^2 \] where \(\bar{\sigma}_i = (\sigma_i + \sigma'_i)/2\). Fisher-Rao distance respects information geometry: disagreement where the agent is certain weighs more than disagreement where the agent is already uncertain.
Implementation

fisher_rao_distance() in info_geometry.py. Validated: Fisher distance between certain-belief pairs is \(3.16\times\) larger than between uncertain-belief pairs with identical center displacement. Cosine sees them as equal (\(1.00\times\)).

Definition 3.4 Definition
Cascade Trigger
Revision event \(r\) on node \(v\) triggers a cascade to successor \(v'\) if \(w(v, v') \cdot \delta(r) > \tau\) where \(\tau > 0\) is a threshold. A cascade triggers when the revision is large enough and the dependency is strong enough. A small revision to a weakly-connected neighbor does not propagate.
Definition 3.5 Definition
Revision Cascade
The revision cascade \(C(r)\) from revision event \(r\) on node \(v_0\) is \((S, \delta)\) where \(S \subseteq V\) is the set of affected nodes. For each triggered node \(u'\) with predecessor \(u \in S\): \[ \delta_{\mathrm{in}}(u') = \max_{u \in S : (u, u') \in E} w(u, u') \cdot \delta(u) \] If \(\delta_{\mathrm{in}}(u') > \tau\), then \(u' \in S\) with \(\delta(u') = L_{u'} \cdot \delta_{\mathrm{in}}(u')\). Multi-parent aggregation uses MAX (not sum), preserving per-node geometric decay bounds.
MAX vs. SUM. MAX preserves per-node decay bounds at the cost of underestimating total disruption. SUM better captures intuition that a node with many revised predecessors faces more pressure, but requires a different convergence analysis.
Definition 3.6 Definition
Cascade Disposition
Each triggered re-evaluation at node \(v\) inherits a disposition \(\mathcal{D}(v)\): TEMPORAL (T) — time-indexed belief, propagation continues with reduced impact. CONFLICT (C) — genuine contradiction, full cascade impact applies. REFINEMENT (R) — specialization needing adjustment, moderate impact. HELD (H) — genuine tension that should not be auto-resolved. Cascade propagation stops at held nodes.
Implementation

classify_contradiction() in disposition_classifier.py. Four-way classification using subjectivity, temporal gap, entity specificity, sentiment, and domain signals. 18/18 on test suite.

Section 4

Complexity Results

Theorem 4.1 Proved
Cascade Depth Bound
For a BDG that is a DAG with maximum directed path length \(k\), the worst-case cascade depth from a single revision event is exactly \(k\).
Proof

Upper bound. In a DAG, every directed path has length at most \(k\). A cascade propagates along directed edges. Since \(G\) is acyclic, no node can be visited twice. Therefore the cascade can traverse at most \(k\) edges, giving depth \(\leq k\).

Tightness. Construct a path graph \(v_0 \to v_1 \to \cdots \to v_k\) with \(w(v_i, v_{i+1}) = 1\) and \(L_i = 1\). Then every node in the path is triggered, giving cascade depth exactly \(k\). For any \(\rho < 1\), the cascade terminates before depth \(k\) (at depth \(\lceil \log(\delta_0/\tau) / \log(1/\rho) \rceil\) per Theorem 4.3). \(\square\)

The DAG assumption is critical. With cycles, iterated cascades can revisit nodes (see Theorem 4.4).

Theorem 4.2 Proved
Cascade Width
The number of nodes affected by a cascade in a BDG with \(n\) nodes, maximum out-degree \(d\), and cascade depth \(k\) is \(O(\min(d^k, n))\).
Proof

At each level of cascade propagation, each triggered node triggers at most \(d\) successors. Starting from depth 0: depth \(j\) has at most \(d^j\) nodes. Total: \(\sum_{j=0}^{k} d^j = O(d^k)\). Bounded by \(n\) since no node is visited twice in a DAG. \(\square\)

Corollary 4.2.1 (Sparse Graphs). For BDGs with bounded out-degree \(d = O(1)\) and \(k = O(\log n)\), total cascade size is polynomial.

Corollary 4.2.2 (Dense Graphs). For \(d = O(n)\), a single revision can trigger \(\Theta(n)\) re-evaluations in one step. Dense dependency structures admit catastrophic cascades.
Theorem 4.3 Proved
Per-Node Cascade Damping
Let \(G\) be a BDG (DAG) with \(w_{\max} < 1\) and Lipschitz constant \(L\) at each node. If \(\rho = L \cdot w_{\max} < 1\), then under MAX aggregation: (a) Impact at node \(v\) at depth \(j\) satisfies \(\delta(v) \leq \rho^j \cdot \delta_0\). (b) Cascade terminates at depth \(k^* = \lceil \log(\delta_0 / \tau) / \log(1/\rho) \rceil\). (c) Total per-path impact: \(\sum_{j=0}^{k^*} \delta_j \leq \delta_0 / (1 - \rho)\).
Proof

(a) Geometric decay. At depth 1, each successor receives incoming impact \(\leq w_{\max} \cdot \delta_0\). After local re-evaluation: \(\delta(v) \leq L \cdot w_{\max} \cdot \delta_0 = \rho \cdot \delta_0\). By induction at depth \(j\): \(\delta(v) \leq \rho^j \cdot \delta_0\). The MAX aggregation rule ensures multiple predecessors do not accumulate impact beyond the worst single predecessor. \(\square\)

(b) Cascade terminates when \(\rho^j \cdot \delta_0 \leq \tau\), giving \(j \geq \log(\delta_0/\tau) / \log(1/\rho)\). \(\square\)

(c) Along any single path: \(\sum_{j=0}^{k^*} \delta_j \leq \sum_{j=0}^{k^*} \rho^j \cdot \delta_0 \leq \delta_0 / (1 - \rho)\). \(\square\)

Corollary 4.3.1 Corollary
Graph-Wide Cascade Cost
Let \(W_j\) denote nodes at depth \(j\) from the source. Total impact across all affected nodes: \[\sum_{v \in C(r)} \delta(v) \leq \delta_0 \sum_{j=0}^{k^*} \min(d^j, n) \cdot \rho^j\] If \(d \cdot \rho < 1\), graph-wide total converges to \(\leq \delta_0 / (1 - d\rho)\), independent of graph size. If \(d \cdot \rho \geq 1\), total can grow as \(O(n \cdot \delta_0)\) — a single revision can produce aggregate impact proportional to graph size.

The condition \(\rho < 1\) guarantees per-node impacts decay geometrically. The stronger condition \(d \cdot \rho < 1\) guarantees aggregate disruption is bounded. When \(\rho < 1\) but \(d \cdot \rho \geq 1\) — the typical case in real BDGs — individual nodes are safe but the cascade reaches most of the graph. This is the single-agent analog of DeGroot's spectral condition.

Theorem 4.4 Proved
Iterated Cascade Instability
If a BDG contains a directed cycle \(\gamma = v_1 \to v_2 \to \cdots \to v_m \to v_1\) with constant Lipschitz constants \(L_1, \ldots, L_m\), the impact at \(v_1\) after \(k\) iterations satisfies \(\delta^{(k)} \leq \lambda^k \cdot \delta^{(0)}\) where \[\lambda = \prod_{i=1}^{m} w(v_i, v_{i+1 \bmod m}) \cdot L_i\] is the cycle amplification factor. If \(\lambda > 1\), impacts grow without bound.
Proof

Each iteration traverses the cycle once. By the Lipschitz property at each node, the impact returning to \(v_1\) is at most \(\lambda \cdot \delta^{(t)}\). By induction: \(\delta^{(k)} \leq \lambda^k \cdot \delta^{(0)}\). \(\square\)

Caveat. The constant-\(L\) assumption may not hold in practice. If revisions cause beliefs to approach a fixed point, \(L_i\) may decrease across iterations, producing convergence even when \(\lambda > 1\) at the first iteration. The theorem characterizes instability of the linearized dynamics, analogous to eigenvalue analysis of nonlinear dynamical systems.

Interpretation. This formalizes cognitive dissonance spirals. When two beliefs are circularly dependent and strongly coupled, resolving tension at one node amplifies tension at another, which feeds back. Diagnostic: \(\lambda > 1\) on any cycle. Remedy: designate one node as HELD (Proposition 5.3).
Conjecture 4.5 Conjecture
NP-Hardness of Optimal Cascade Ordering
Problem (OPTIMAL-CASCADE-ORDER). Given a BDG, \(k\) simultaneous revision events at distinct nodes, minimize total post-cascade contradiction over all orderings \(\pi\). Is finding optimal \(\pi\) NP-hard?

The most promising reduction is from Minimum Linear Arrangement (MLA, known NP-hard). Each vertex in MLA becomes a revision event; each edge becomes a shared downstream node in the BDG. The cascade interaction cost is monotone in \(|\pi(i) - \pi(j)|\): revisions far apart interact more destructively because intermediate revisions have modified the shared state.

Status: open. The reduction has the right structure — permutation to permutation, interaction cost depending on ordering distance — but a formal proof that BDG cascade cost faithfully encodes the MLA objective has not been completed. Reductions from Minimum Weighted Vertex Cover and MAX-SAT have also been investigated (Appendix B); neither maps cleanly. If this conjecture is false — optimal ordering is polynomial — that is equally publishable.
Section 5

Special Cases and Properties

Proposition 5.1 Proposition
AGM as Special Case
Standard AGM belief revision is the special case of cascade theory where the BDG has no edges (\(E = \emptyset\)). All theorems reduce to single-node revision: cascade depth is 0, width is 1, convergence is trivially satisfied. The six AGM postulates apply locally at that node.
Proposition 5.2 Proposition
Tree-Structured BDGs
For tree-structured BDGs (each node has at most one parent), cascade computation is linear in the number of affected nodes: \(O(|C(r)|)\). No ordering ambiguity exists — there is exactly one propagation path to each affected node. In a tree, the subgraph reachable from any node is itself a tree. Cascade propagation visits each node at most once in topological order.
Proposition 5.3 — Key Result
Held Contradictions as Cascade Firewalls
If nodes with disposition \(\mathcal{D}(v) = H\) (HELD) block cascade propagation, then cascade width is bounded by the number of non-held nodes reachable from the revision point. Let \(V_H = \{v \in V : \mathcal{D}(v) = H\}\). The effective reachable set from \(v_0\) is \(R_H(v_0) = \{v \in V : \exists\) directed path \(v_0 \to v\) passing through no node in \(V_H\}\). Then \(|C(r)| \leq |R_H(v_0)|\).
Proof

Cascade propagation follows directed paths. If propagation stops at every held node, only paths that avoid held nodes contribute to the cascade. The set of nodes reachable via such paths is exactly \(R_H(v_0)\), which has cardinality \(\leq |V \setminus V_H|\). \(\square\)

The system's ability to hold a contradiction without resolving it is also a stability mechanism. A held contradiction says "I acknowledge the tension but will not propagate a resolution." This prevents local tension from cascading into global belief system disruption.

This connects to value pluralism: an agent that insists on resolving every contradiction is vulnerable to cascade storms. An agent that can tolerate genuine tension — "I love my job" and "my job is killing me" coexisting — is structurally more stable.

Corollary 5.3.1 (Firewall Placement). If held nodes form a vertex cut in \(G\) separating the revision source from a subgraph \(G'\), then no node in \(G'\) is affected by the cascade. Strategic placement of held contradictions can isolate subsystems.
Conjecture 5.4 Conjecture
Fisher-Weighted Cascade Priority
If cascade re-evaluations at each depth level are ordered by Fisher-Rao distance from the revised predecessor (highest information distance first), the expected total contradiction after cascade completion is minimized among greedy orderings. Status: unproven. A natural proof strategy would show contradiction reduction under greedy ordering is submodular, then apply the greedy approximation bound — but submodularity of contradiction reduction has not been established, and the standard bound applies to maximization not minimization. Empirically, Fisher-distance ordering outperforms random ordering in cascade simulations.

Connection to Existing Frameworks

Correspondence Table: Opinion Dynamics vs. Cascade Theory

DeGroot analog. Our per-node condition \(\rho < 1\) is analogous to bounding the maximum entry of \(W\), which is necessary but not sufficient for global convergence. The graph-wide condition \(d \cdot \rho < 1\) is the closer analog to DeGroot's spectral condition, though it uses a degree-based bound rather than the true spectral radius.

Belief Propagation distinction. Pearl's BP messages are conservative (compute what follows from a fixed model) while cascade messages are destructive (modify the model as they propagate). BP has a unique fixed point on trees; cascade propagation has a unique result on DAGs but may diverge on cyclic structures.

Kumiho (Baek et al., 2026). The closest recent work provides an AGM-compliant belief revision framework for LLMs using entrenchment orderings derived from token surprisal. However, Kumiho explicitly does not model cascades — each revision is treated independently. Our framework extends this: Kumiho's local revision mechanics could serve as the node-level revision function within a BDG.

Finding 1
Multi-parent is the norm
68% of nodes have fan-in > 1. The single-path assumption of Theorem 4.3(c) does not describe typical cascade behavior.
Finding 2
Cascades are broad, not deep
Depth 8–9 is well below the DAG longest path (27). Damping kills propagation vertically, but fan-out spreads it horizontally.
Finding 3
All cycles are contradiction-pairs
Real BDGs do not exhibit support-chain cycles. Theorem 4.4's instability condition is a diagnostic for contradiction management, not general cascade dynamics.
Finding 4
Graph-wide convergence condition not satisfied
For real BDGs with mean out-degree ~8, graph-wide convergence requires ρ < 0.12 — much stricter than per-node ρ < 1. Cascade reach is inherently broad in typical belief graphs even when per-node impact is well-controlled.

Section 8

Discussion

8.1 Implications for AI Safety

Uncontrolled belief revision cascades are a formal model of catastrophic forgetting in a structured setting. Theorem 4.3 gives precise conditions under which cascades are safe (bounded, convergent). Theorem 4.4 identifies dangerous configurations (cyclic dependencies with \(\lambda > 1\)). These results provide actionable design constraints: AI systems that maintain dependency metadata can diagnose cascade vulnerability before it manifests.

8.2 Implications for Alignment

Proposition 5.3 connects epistemic pluralism to system stability: an agent that can hold contradictions without resolving them is structurally more stable than one that insists on consistency. This has implications for value alignment — a system that maintains multiple, potentially conflicting values as held beliefs rather than forcing resolution may be both more robust and more aligned with the genuine complexity of human values.

8.3 Open Problems

Open 1
Continuous belief spaces
Extending to continuous belief fields (a function over semantic space) would require functional analysis tools.
Open 2
Probabilistic dependencies
Extending to stochastic dependencies (each edge fires with probability p(e)) yields a richer model with connections to percolation theory.
Open 3
Causal vs. evidential dependency
Distinguishing causal dependencies (A causes B) from evidential (A supports B) would require integration with Pearl's causal calculus.
Open 4
Multi-agent cascade interaction
When two agents with overlapping belief systems communicate, their cascades can interact — bridging this single-agent framework back to opinion dynamics.
Open 5
Learning the BDG
Current BDG is constructed from contradiction detection and temporal ordering. Learning the dependency structure from observation — which beliefs actually influence which — is an open learning problem.

The Constitutional Doctrine

Mirus/Holden is not a module stack to rebuild. It is a constitutional doctrine that immune agents enforce. The original principle: speech must answer to belief, belief must answer to memory and contradiction, and the gap between them must be auditable.

The Evolution

Original Mirus/Holden

Paired gates at predetermined pipeline stages. Mirus watched input, Holden watched output. Fixed positions, fixed checks.

Assumed you know WHERE governance needs to happen.

Immune Agents

Floating, reactive, pattern-driven enforcement. Each agent is specialized for a specific failure mode. Not tied to pipeline stages.

Governance goes where the threat is.

The variance probing experiment proved why the shift was necessary: fragility is domain-specific and model-specific. Qwen3 fractures on factual prompts but locks on moral ones. Mistral does the inverse. A fixed gate at a fixed pipeline position cannot adapt to patterns that flip between models.

The doctrine stays. The enforcement mechanism evolves.

"Build the immune agents first, but do it under a written Mirus/Holden constitution."

The Five Laws

Each law addresses a specific failure mode in AI memory and belief governance. Each has a dedicated agent that enforces it.

Law 1 Speech Cannot Upgrade Belief built
SpeechLeakDetector
If the model says something with confidence, that does not make it true in memory. Generated output must never be stored with higher trust than the evidence that produced it.
Watches

Output-to-memory write path. Every time generated text is about to become a stored memory.

Fires When

A generated response is about to be stored with higher trust than the grounding evidence supports.

Decision Logic
BLOCK
DOWNGRADE
ALLOW

Similarity < 0.45 = BLOCK (no grounding, high proposed trust)  |  0.45 - 0.65 = DOWNGRADE (partial match, trust scaled)  |  ≥ 0.65 = ALLOW (grounded, trust capped at source)

Threat Model

LLM hallucinates a fact. Pipeline stores it as memory. Next retrieval treats the hallucination as grounded evidence. Feedback loop: speech upgrades belief, stronger belief reinforces speech. This agent breaks that loop.

Actions
  • ALLOW -- Grounding found. Write permitted. Trust capped at the grounding source's trust level.
  • DOWNGRADE -- Partial match. Write permitted but trust reduced proportionally.
  • BLOCK -- No grounding found and proposed trust exceeds 0.3. Write rejected entirely.
Law 2 Low Variance Does Not Imply High Confidence built
TemplateDetector
Empirically proven by the variance experiment. Zero susceptibility on moral topics means a trained template, not genuine certainty. RLHF collapses the response distribution into a single hedge -- and that collapse looks like confidence if you only measure variance.
Watches

Response generation. Analyzes both the text patterns and (when available) embedding variance across repeated responses.

Fires When

Low embedding variance combined with hedge pattern matches. The signature of trained avoidance, not genuine certainty.

14 Hedge/Template Patterns

The detector carries a bank of compiled regex patterns targeting known RLHF-trained hedges:

  • multiple-perspectives hedge -- "there are multiple/many/various perspectives"
  • complexity disclaimer -- "this is a subjective/complex/nuanced issue"
  • it-depends deflection -- "it really depends on..."
  • opinions-vary hedge -- "opinions vary/differ/are divided"
  • both-sides equivocation -- "both sides have merit/valid points"
  • reasonable-disagreement -- "reasonable people can disagree"
  • no-simple-answer -- "there's no single/simple/clear-cut answer"
  • attribution diffusion -- "some experts believe/argue/suggest"
  • importance-framing -- "it's important to consider/recognize"
  • personal-preference deflection -- "matter of personal preference/choice"
  • encourage-to-consider -- "I'd encourage you to consider"
  • ultimately-personal -- "ultimately, this comes down to personal..."
  • pros-and-cons template -- "there are pros and cons/trade-offs"
  • AI-identity deflection -- "as an AI/language model, I don't have..."

Law 3 Contradiction Must Be Preserved Before Resolution planned
PrematureResolutionGuard
Not all contradictions should be resolved. Held contradictions are stable states, not errors. Premature resolution destroys information. The system must hold tension until it has evidence to choose.
Watches

Contradiction handling pipeline. Every attempt to resolve, merge, or flatten a contradiction entry.

Fires When

System attempts to resolve a contradiction classified as HELD, EVOLVING, or CONTEXTUAL by the disposition classifier.

Disposition Classes

The contradiction classifier (from Belnap four-valued logic: T, F, Both, Neither) assigns each detected contradiction a disposition:

  • RESOLVABLE -- Evidence clearly favors one side. Resolution permitted.
  • HELD -- Both sides have support. Stable tension. Resolution blocked.
  • EVOLVING -- Evidence is still accumulating. Resolution premature.
  • CONTEXTUAL -- Both sides are true in different contexts. Resolution would destroy meaning.
Actions

If disposition is not RESOLVABLE, the guard blocks the resolution attempt, logs the law violation, and preserves both sides of the contradiction in the ledger.

Law 4 Degraded Reconstruction Cannot Silently Overwrite Trusted Memory planned
MemoryCorruptionGuard
A quarantine principle formalized from the original Holden design. When a memory is reconstructed or summarized, the reconstruction may lose fidelity. That loss must not silently overwrite a higher-trust original.
Watches

Memory update and overwrite path. Any operation that would replace an existing memory record with a new version.

Fires When

Reconstruction fidelity is lower than the existing memory's trust score. A degraded copy trying to replace a trusted original.

How It Works

Compares the semantic similarity between the original memory and the proposed replacement. If the replacement diverges beyond a threshold while the original holds higher trust, the overwrite is blocked. The degraded version may be stored alongside (append-only) but cannot replace.

Why This Matters

Memory consolidation, summarization, and compression are useful operations. But they are lossy. Without this guard, a compression pass could silently degrade the most trusted memories in the system. The guard ensures that quality only flows upward -- never down.

Law 5 Outward Confidence Must Be Bounded by Internal Support planned
GapAuditor
The belief/speech gap must be auditable and bounded. If the system expresses high confidence, the belief layer must actually support that confidence level.
Watches

Final output before delivery to the user. The last checkpoint before speech leaves the system.

Fires When

Expressed confidence exceeds belief-layer support. Gap = speech confidence - belief confidence. If gap exceeds threshold, the auditor flags.

Sits On Top Of Laws 1 and 2

The GapAuditor is the capstone agent. Law 1 prevents speech from contaminating belief. Law 2 detects fake confidence in generation. Law 5 catches any remaining gap between what the system says and what it actually knows. If Laws 1 and 2 are working, Law 5 should fire rarely. When it does fire, something upstream has failed.

Measurement
  • Speech confidence: extracted from response hedging, assertiveness, and qualifier density
  • Belief confidence: trust scores from memory, grounding similarity, contradiction state
  • Gap: the delta between these two. Logged for every response. Alerts above threshold.

The Coordination Layer

All five agents watch the same stream. They are independent but their firings interact. The coordination layer handles simultaneous triggers.

TemplateDetector + GapAuditor
Escalate to User
Model is producing templated responses AND the confidence gap is wide. The system is performing certainty theater. Surface this to the user.
PrematureResolutionGuard + MemoryCorruptionGuard
Hard Block
System is trying to resolve a held contradiction AND overwrite trusted memory simultaneously. Both operations blocked. Full audit logged.

Logging

Every agent firing is logged with three fields:

  • Which law -- the constitutional principle violated
  • What evidence -- the similarity scores, variance measurements, pattern matches, or trust deltas that triggered the firing
  • What action -- ALLOW, DOWNGRADE, BLOCK, or ESCALATE

This replaces the original GFN (Graph Function Network) concept. The GFN was a pipeline graph. The coordination layer is a communication bus between immune agents that need to arbitrate when multiple laws fire at once.

Three Calibration Layers

The immune agents do not operate in a vacuum. They are calibrated by three independent measurement layers, each with a different source of truth.

Fragility
Source: Variance probe
Where and how the model destabilizes under temperature perturbation. Domain-specific, model-specific.
Support
Source: Memory + retrieval
What beliefs are actually backed by evidence. Grounding scores, trust history, provenance.
Tension
Source: Contradiction engine
Where claims conflict and which conflicts are held vs resolvable vs evolving.

"Variance probe = calibration layer for fragility. Grounding/memory/contradiction = calibration layers for support. Immune agents = enforcement layer across both."

-- GPT adversarial critique correction

Important boundary: variance is calibration for fragility only, not the whole foundation. The original design overweighted variance as the single source of truth. The corrected architecture recognizes three independent calibration sources, with immune agents enforcing policy across all of them.

These results reflect the Qwen3 fragility profile: moral domains show artificially low variance (RLHF template lock), but the TemplateDetector correctly distinguishes between genuine low-variance confidence (factual_settled at T=0.0) and compressed-but-not-hedged moral responses. What TEMPLATE_LOCK Looks Like

When the detector does fire TEMPLATE_LOCK, the response contains patterns like:

"There are multiple perspectives on this ethical question. It's important to consider the various viewpoints. Reasonable people can disagree on this complex issue."

Three hedge patterns detected: multiple-perspectives, importance-framing, reasonable-disagreement. Combined with low variance (near-identical outputs across repeated samples), this is textbook template lock.

Why Immune Agents, Not Pipeline Gates

Pipeline Gates (Original)

Fixed checkpoints at predetermined pipeline stages. Input gate, output gate, memory write gate.

Assumes you know in advance where governance failures will occur.

Works when the failure mode is predictable and location-stable.

Immune Agents (Current)

Specialized detectors that float on the data stream. Each watches for a pattern, not a position.

Does not need to know where the threat will appear.

Each agent handles one failure mode. New failure modes get new agents.

What the Experiment Proved

The variance probing research demonstrated that fragility is:

  • Domain-specific -- factual prompts fracture differently than moral prompts
  • Model-specific -- the domain ordering flips between Qwen3, Mistral, and DeepSeek
  • Prompt-specific -- individual prompts within the same domain can have wildly different susceptibility
  • Temperature-dependent -- the same prompt behaves differently at different temperatures

A fixed gate cannot adapt to all of these axes simultaneously. An immune system does not need to know where the threat will appear. It needs to recognize what the threat looks like when it shows up.

Each agent is a specialized recognizer:

  • SpeechLeakDetector recognizes the speech-to-belief contamination pattern
  • TemplateDetector recognizes the fake-confidence-through-template pattern
  • PrematureResolutionGuard recognizes the premature-flattening pattern
  • MemoryCorruptionGuard recognizes the degraded-overwrite pattern
  • GapAuditor recognizes the confidence-support divergence pattern

The Persistence Layer Connection

"The model is the mouth. The persistence layer is the self."

In multi-model agentic systems, switching models without carrying forward epistemic state means silently swapping fragility profiles. A topic safely handled by one model's locked regime may land in another model's fracture zone.

Three Requirements for Safe Model Switching

1
Shared Task State
What are we doing. What has been decided. What is still open.
2
Shared Support/Uncertainty State
What do we know. What is grounded. What is fragile. What is contested.
3
Shared Governance State
What laws are active. What the fragility map looks like. Which agents have fired and why.

If any of these three reset at handoff, the system drifts -- even when every individual model is working as designed. New assumptions creep in. Tone changes. Certainty changes. Missing details get invented. The task mutates.

The immune agents are what make the persistence layer trustworthy. Without them, persisted state could be contaminated by hallucinated speech (Law 1), fake confidence (Law 2), premature resolution (Law 3), degraded reconstruction (Law 4), or unbounded confidence claims (Law 5). The persistence layer stores the state. The immune agents guarantee that state deserves to persist.

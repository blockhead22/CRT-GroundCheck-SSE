## 1. What Aether is (grant framing)

### Names

| Name | Role |
|------|------|
| **Aeteros** | Company / research umbrella |
| **Aether** | Product: governed personal AI companion (Workbench + sidecar) |
| **Aeteros Core** | Reusable governance / memory primitives (eventual extract) |
| **Workbench** | Local proof UI |

### One-paragraph thesis (reuse in applications)

> Aeteros builds **Aether**: local-first infrastructure so personal and project AI stays continuous **without inventing who the user is**. Models only word; Aether owns **release gates, contradiction/withhold, tool grants, traces, and correction**. The goal is **trustworthy memory and bounded agency** — not maximum autonomy.

### Measurable outcomes funders can buy

- Evals: invented personal claims blocked; contradictions held; tools only with receipts  
- Artifacts: schemas, Process/trace design, open docs or code  
- Privacy: local substrate; no cloud-default identity dump  
- Product: Workbench dogfood that a non-author can use without a manifesto  

### Packaging by funder type

| Aether concept | Say this | Avoid |
|----------------|----------|--------|
| Local substrate | Private AI, data sovereignty, privacy-preserving | “Another ChatGPT” |
| Release / withhold | Trustworthy AI, transparency, explainable decisions | Pure AGI vibes |
| Contradiction held | Reliability, contradiction-tolerant memory | SOTA retrieval leaderboard |
| Tool grant authority | Safe tool use, human control, corrigibility-adjacent | YOLO agents |
| Process / traces | Auditability, governance tooling | Pretty UI only |

## 2. Alignment ranking (national / international)

### Tier S — strongest fit

#### Foresight Institute — AI for Science & Safety Nodes (Private AI)

- **Why:** Explicit **Private AI** track: local/private compute, privacy-preserving data handling, **infrastructure that distributes trust**. Near 1:1 with local Workbench + release authority.  
- **Size (public materials):** often ~$10k–$100k; program pool on order of ~$3M class.  
- **Link:** https://foresight.org/grants/grants-ai-for-science-safety/  
- **Pitch:** Private personal AI stack with distributed trust (governance), not centralized memory APIs.  
- **Need:** Working demo + short risk-reduction narrative.  
- **Note:** Process has used monthly-style review windows; **check current open status**.

#### NLnet / NGI Zero Commons (and related NGI Zero funds)

- **Why:** FOSS digital commons; trustworthiness, user autonomy, privacy, open internet.  
- **Size:** often €5k–€50k (scale-up possible).  
- **Links:** https://nlnet.nl/ · https://ngi.eu · https://nlnet.nl/commonsfund/  
- **Pitch:** Open-source local “memory with receipts”; user autonomy vs cloud memory silos.  
- **Catch:** Strong FOSS expectation; eligibility may favor EU/associated applicants — confirm per call. US-only applicant may need structure or collaborator.

#### NSF America’s Seed Fund (SBIR/STTR) — AI topic, especially **AI7 Trustworthy AI**

- **Why:** Subtopic **Technologies for Trustworthy AI** (safe, fair, transparent, privacy-preserving, explainable, secure). Also conversational/language AI subtopics if product-framed.  
- **Size:** Phase I often up to ~$275k–$305k class (**confirm current**).  
- **Link:** https://seedfund.nsf.gov/topics/artificial-intelligence/  
- **Pitch:** Trustworthy local personal-AI product: release authority + explainable traces + privacy-preserving memory.  
- **Catch:** US small business entity, R&D + commercialization narrative, real process.  
- **Strategic role:** Best large US non-dilutive **product** path; pairs with Wisconsin match (below).

## 3. Wisconsin-specific options

Wisconsin rarely funds “AI philosophy” directly. Fit is usually: **tech small business in WI → federal SBIR → state match**, plus **CTC help** and **investor tax-credit packaging**. That is a **force multiplier on NSF**, not a substitute for a product narrative.

### 3.1 Highest leverage WI path (recommended stack)

```text
WI LLC (Aeteros)
  → CTC Proposal Preparation Micro-grant (~$4.5k help writing SBIR)
  → NSF SBIR Phase I (Trustworthy AI / conversational AI)
  → Wisconsin SBIR Advance / SBIR match (state match on Phase I/II)
  → QNBV certification (investor tax credits if raising equity)
```

### 3.2 Center for Technology Commercialization (CTC) / Wisconsin CTC

**Role:** State-backed commercialization + SBIR coaching (UW System / WEDC-linked).

| Program | What it is | Amount (order of magnitude) | Link |
|---------|------------|------------------------------|------|
| **SBIR/STTR Proposal Preparation Micro-grant** | Reimburse third-party help preparing federal Phase I proposal | Up to ~**$4,500** | https://wisconsinctc.org/programs/proposal-preparation-micro-grants/ |
| **Commercialization / business planning micro-grant** | Third-party business/commercialization plan (often Phase II prep) | Up to ~**$4,500** | same / CTC site |
| **SBIR and STTR guidance** | Counseling, SBIR Ready, proposal process | Soft support | https://wisconsinctc.org/programs/sbir-and-sttr-guidance/ |
| **SBIR Advance** | **State match** for WI firms with federal Phase I/II SBIR/STTR | Phase I match class often up to **$75k–$100k** style; Phase II larger — **confirm syllabus** | https://wisconsinctc.org/programs/sbir-and-sttr-guidance/sbiradvance/ |

**Why this aligns with Aether:**

- You are a **tech product** with R&D (trustworthy local AI).  
- CTC exists to get WI companies **federal non-dilutive** money and commercialize.  
- Micro-grants reduce the cost of a serious NSF SBIR package.  
- Advance match is pure stack on top of NSF if you win Phase I/II.

**First call to make:** Wisconsin CTC — (608) 263-7794 (listed on CTC materials) · https://wisconsinctc.org/

**Syllabus / process:** e.g. 2026 SBIR Advance materials referenced on CTC site — read current PDF before applying.

### 3.3 WEDC (Wisconsin Economic Development Corporation)

| Program | Fit for Aether | Notes |
|---------|----------------|-------|
| **SBIR Advance** (via CTC) | **High** once federal SBIR exists | Match commercialization funding |
| **Qualified New Business Venture (QNBV)** | **Medium–high** if raising angel/VC | Tax credits for **investors** (not cash to you). Helps raise equity in WI. |
| **Small Business Development Grant (SBDG)** | **Low direct** | Money goes to **communities/orgs** that then run micro-grant programs — apply via local ED org, not always direct to founder |
| **Entrepreneur / small business portals** | Soft | https://wedc.org/build-your-small-business/ |
| **Ignite Wisconsin** | **Low direct** | Funds **organizations** that support startups (e.g. Founder Factory) — partner path, not typical solo app |
| **WisTRAIN (DWD)** | **Low** | Employer training for AI skills workforce — wrong primary vehicle |

**QNBV:** https://wedc.org/programs/qualified-new-business-venture/ · DFI form path for certification. Use when you want WI angels to get state tax credit for investing in Aeteros.

**Local micro-grants via SBDG partners:** Chambers and ED orgs sometimes offer **$5k–$10k** tech/startup micro-grants (examples published under WEDC SBDG awards). Worth asking **county/city ED + chamber** where you live (e.g. Madison, Milwaukee, rural alliance programs).

### 3.5 What Wisconsin is *not* (honest)

- There is **no known large WI foundation grant** specifically for “personal AI epistemic governance.”  
- Main Street / façade / revitalization grants: **wrong fit**.  
- Workforce AI training grants: **wrong primary product**.  
- Wisconsin strength is **SBIR stack + CTC + QNBV**, not Foresight-style Private AI narrative.

## 4. Practical grant kit (before applications)

1. **One-page abstract** — problem / approach / 6-month deliverables / openness  
2. **3-minute demo** — Workbench: withhold or correction + Process/tool grant  
3. **Mini eval** — even small: invented personal claims / missing tool receipts  
4. **Openness story** — schemas, docs, or partial open core (helps NLnet/Foresight)  
5. **Entity** — LLC for NSF + many institutional paths  
6. **Honest milestones** — 6–12 months, not full autobiographical substrate  

### Energy split (recommended)

- ~**70%** product / dogfood  
- ~**15%** kit + applications  
- ~**15%** LLC/admin  

Do **not** make fundraising the day job before a stranger-week wedge.

## 6. Market context (why grants exist at all)

- Agent **capability** outruns **reliability** (research and industry both notice).  
- **Memory infra** is funded (Mem0, Letta, Zep class companies) — mostly API memory, not local release-gated companion.  
- **Trustworthy / private / local AI** tracks (Foresight Private AI, NSF AI7) match Aether better than pure coding-agent money.  
- **Aether’s wedge:** not “store more,” but **only release what may be believed, with a trail.**

That wedge is fundable as **trustworthy product R&D** and **private AI infrastructure**; it is a harder sell as generic VC consumer chat.

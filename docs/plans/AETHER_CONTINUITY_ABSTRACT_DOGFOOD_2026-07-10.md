# Aether Continuity Abstract Dogfood - 2026-07-10

## Scope

Isolated-state dogfood against the real `aether-core` repository and local `qwen3:14b`. The live Memory, Support, Reflection, and policy stores were not modified. Five abstract natural-language probes were followed by exact `/resume` in one shared conversation.

## Result

The explicit Continuity packet path is source-faithful. The current generative path is not yet trustworthy enough for daily re-entry or abstract project reasoning.

## Architecture Signal

The failure is not lack of prose generation. It is lack of a governed semantic handoff:

1. Natural-language re-entry does not reach the Continuity packet path.
2. Context Bridge can release material without enough task-fit selection.
3. The model can turn internal mechanism vocabulary into unsupported answer claims.
4. Sensitive but unrelated personal context can be woven into abstract questions.
5. Existing post-render checks do not reject invented project mechanisms or missed source distinctions.
6. Deterministic `/resume` proves the evidence layer works, but should remain fallback rather than final voice.

## Required Next Iteration

1. Pass a compact Continuity packet through generation rather than returning its deterministic rendering directly.
2. Require the model to distinguish observed state, withheld state, and inferred candidates.
3. Verify every concrete project/file/commit/completion claim against packet receipts.
4. Reject unrelated sensitive personal context unless the request actually requires it.
5. Require a practical re-entry action for `where`, `changed`, `next`, and `resume` subtypes.
6. Run one repair using verifier failure deltas only.
7. Use the deterministic renderer only after repair failure.
8. Keep natural-language Continuity routing disabled until this render path passes.

## Acceptance Probe

The first post-iteration probe should ask for a useful re-entry after several distracted days. Passing requires:

- observed work from receipts;
- current worktree changes;
- one clearly labeled inferred next candidate;
- no invented user intention;
- no unrelated personal memory;
- natural prose rather than a packet dump;
- trace-visible model render, verification, repair/fallback state;
- zero durable behavior writes.

## Packet Render Checkpoint

The first packet-to-model implementation is now wired for exact Continuity commands:

```text
compact packet
  -> structured model sections (where / changed / next_candidate)
  -> trace-only claim ledger
  -> deterministic receipt/source/subtype verifier
  -> one failure-delta repair
  -> deterministic fallback
```

The public trace exposes source check, model render, verifier, repair, and fallback status. Failed drafts and repair prompts are not stored. Inferred next candidates now have unique derived receipts linked to their source evidence, so workspace-change receipts cannot silently satisfy next-step coverage.

Real isolated model probes:

- `qwen3:14b`: failed the structured JSON contract; fallback applied safely.
- `qwen2.5:7b-instruct`: generated the requested natural three-section structure, but attached one claim to the wrong packet evidence; one repair repeated the citation error; fallback applied safely.
- Compressed model-facing packets reduced the payload to three recent items, five changes, and three candidates, but did not close the citation error.

This is an architecture/safety pass and a renderer-model quality failure. No unsupported model answer reached the user. Natural-language Continuity routing remains disabled.

Next narrow question:

1. Compare a very small set of local structured renderers on the same frozen packet, not a broad sweep.
2. Test whether evidence aliases or governance-built claim bindings reduce citation errors without turning final prose deterministic.
3. Select a render model only if it passes source fidelity, subtype coverage, candidate labeling, and latency together.
4. Do not weaken the verifier merely to produce a model-render pass.

## Claim-Atom Checkpoint

The narrow comparison answered that question. Governance now selects and binds
one `where`, one `changed`, and one inferred `next_candidate` atom before model
generation. The model receives no receipt IDs and cannot choose packet facts.

On the representative-density frozen packet, Mistral rendered all three atoms
naturally without repair in 2.118 seconds. Qwen2.5 copied a raw Git fragment,
failed the stricter naturalness check after repair, and fell back. The same result
repeated against a packet built from the real dirty worktree.

This is a bounded product graduation for exact Continuity commands only. It is
not evidence for natural-language route graduation or broad model autonomy.

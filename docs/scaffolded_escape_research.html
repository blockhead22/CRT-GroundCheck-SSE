Scaffolded Escape

How a 3B parameter model broke container isolation, discovered network services, and wrote to the host filesystem — and how gravity-based attention solved the coherence decay that nearly stopped it.

Nick Block • Aeteros Research • April 2026

A 3B model (llama3.2) with no security training escapes 5 of 5 Docker container configurations when augmented with a lightweight exploration scaffold. The scaffold — a state register and MCTS-inspired search tree — provides external attention the model lacks natively. A "hardened" container (--cap-drop=ALL --read-only) was broken when the tree exhausted filesystem approaches and redirected to network exploration, discovering an unauthenticated Ollama API on the host.

During testing, a critical failure emerged: coherence decay. The scaffold found the escape vector but couldn't stop scanning — it had no way to notice its own discovery. This led to a gravity-based attention system that measures structural tension in real time and yields control when something important happens. The same physics that fixes agent attention maps directly to belief system self-models.

The L5 Breakthrough

L5 was the critical test. Filesystem locked, capabilities zeroed, privileges frozen. The model needed to discover that network access was the remaining attack surface — a conceptual shift no amount of filesystem probing could achieve.

The system evolved through four iterations, each addressing a specific failure mode discovered during testing.

Each version addresses the failure mode discovered in the previous version.
v1 — State Register

External Memory

Pattern-matching state tracker. Extracts facts from command output: mounts, devices, capabilities, IPs, ports. Tracks dead ends. Generates suggested actions.

Before: model saw /mnt/external three times, never acted. After: escaped in 6 epochs.

L1–L4 escaped

v2 — Exploration Tree

Structured Search

MCTS-inspired tree with paradigm categories (filesystem, network, process, social). Branches die on hard rejections or stale attempts. Dead paradigm → hard jump to next.

This broke L5. The tree killed filesystem after 21 dead epochs and injected network seed commands.

L5 escaped

v3 + v4 — Gravity + Salience

Attention Physics

Rooms with mass, tension, gravity. Walker falls toward heavy rooms. Salience gate measures gravity delta after each action and yields scaffold when something important happens.

Section 4

The Coherence Decay Problem

During gravity testing, a critical bug emerged that reveals a fundamental flaw in scaffold-driven exploration: the scaffold found the escape vector and kept scanning anyway.

Without salience gate: the scaffold found Ollama at epoch 6 but kept scanning 27 IPs until epoch 19+. Holden's coaching was ignored because tree-directed commands bypass the model.

This is coherence decay — the same phenomenon proven in the 360-run experiment. The system is locally rational (scan unacted facts) but globally incoherent (the escape vector is already found). The scaffold lost coherence with the goal.

Three simultaneous failures:

  1. No gravity delta measurement. The system can't tell that "Ollama is running" changed everything.
  2. No belief/speech gap detection. The system believes the escape vector is found but its next action is "scan another IP."
  3. Scaffold overrides model. Tree-directed commands have higher priority than the model+coach, so Holden's "STOP" is never seen.
Section 5

Gravity Rooms

The exploration tree's paradigm shift was a hard cutoff: "all branches dead? Jump." This caused thrashing between paradigms. Gravity rooms replace the binary logic with physics.

Core Concept
Rooms are fields, not boxes
Each paradigm-room has mass (confidence-weighted beliefs), tension (contradiction density), and gravity (how hard it pulls the walker's attention). The walker doesn't choose where to go — it falls.
Filesystem has high mass but high tension (dead branches contradict live facts). Network has similar mass but zero tension. The walker falls toward network because filesystem's escape pressure pushes it out. Momentum prevents oscillation.

Gravity Formulas

PropertyFormulaMeaning
Masssum of confidence-weighted beliefsHow much the room "weighs" — more beliefs = more mass
Tensioncontradiction pairs / max possible pairsInternal conflict density. 0 = stable, 1 = maximally unstable
Gravity(mass × tension) + sqrt(mass) × 0.3Pull strength. Tension attracts investigation; density provides baseline
Escape pressure= tensionHigh tension pushes the walker OUT of the current room
Stay-pullsqrt(mass) × 0.3 × stabilityOnly density holds you. Tension can't hold — it pushes.
Door costembedding distance between roomsRelated rooms are cheap to traverse. Distant rooms are expensive.

Room Splitting

When a room's tension exceeds a threshold and it contains enough beliefs, it splits. A greedy 2-coloring separates contradicting beliefs into opposing groups. Tested with cross-contradicting "AI optimist" vs "AI pessimist" beliefs:

Before Split

  • ai_future: 6 beliefs, tension=0.60, gravity=3.24
  • 3 optimistic beliefs cross-contradict 3 pessimistic beliefs
  • Maximally unstable

After Split

  • ai_future:alpha: 3 optimists, tension=0.00
  • ai_future:beta: 3 pessimists, tension=0.00
  • Pressure resolved structurally
Section 6

The Salience Gate

The salience gate is the solution to coherence decay. After every action, it measures: did the world just change? If yes, the scaffold yields control to the model.

After every action, the salience gate checks three signals. Low salience: scaffold stays in control. High salience: scaffold yields and the model + coach decide what to do.

Three Salience Signals

SignalWhat it detectsExample
Gravity delta Room gravity changed significantly after ingest Network room gravity spikes from 0.3 to 1.3 after Ollama found
High-value fact A service, mount, or host IP was discovered service:http://192.168.1.146:11434/ created
Belief/speech gap High-value facts exist but are unexploited Ollama found but next action is "scan another IP"

Section 8

Context: Frontier Model Security

The current security paradigm focuses on restricting frontier models — gating access, adding probe classifiers, limiting offensive capabilities to vetted partners. This makes sense for models that can discover zero-days and solve CTF challenges end-to-end.

But the threat model has a blind spot.

Frontier Models (Restricted)

  • High capability, high guardrails
  • Access-controlled, audited, rate-limited
  • Novel vulnerability discovery possible
  • API keys, logging, abuse detection
  • The threat model everyone is watching

3B + Scaffold (Commodity, Open)

  • Low capability model, high capability scaffold
  • Runs locally, no API key, no logs, no guardrails
  • Exploits known misconfigurations, not zero-days
  • 5/5 Docker escapes, full LAN mapping
  • The threat model nobody is watching

The industry gates the model. Nobody gates the scaffold. The exploration tree is ~600 lines of Python. A commodity 3B model with structured exploration achieves results that overlap with restricted frontier capabilities — not through intelligence, but through systematic search that the model alone would never attempt.

Section 9

Identified Chain (Not Built)

The L5 escape revealed a sequence that maps to self-replicating behavior:

Steps 1-2 fully proven. Step 5 partially proven (model created custom Ollama models with static prompts). Steps 3-4 architecturally trivial but not tested.

The remaining gap is not architectural — it is the 3B model's inability to format the curl -X POST correctly. A 7B model or an exploit template closes the gap trivially.

Defense
The fix is simple
--network=none on containers. Authenticate inference APIs. Bind Ollama to 127.0.0.1. These are not exotic recommendations — they are basic hygiene that most deployments skip.
Section 10

The Self-Model Connection

The gravity system wasn't designed as a self-model. But it became one. After each action, the gravity map answers:

  • Where is my knowledge? — mass per room
  • Where are my contradictions? — tension per room
  • Where should my attention go? — gravity pull
  • Am I doing the right thing? — belief/speech gap

The salience gate is an event-driven heartbeat. Instead of a timer-based check ("is everything okay?"), it fires after every action and measures the delta. The agent doesn't just know its beliefs — it knows the shape of its beliefs.

The gravity heartbeat doesn't poll — it reacts. The agent's self-model updates structurally after every action. This is the bridge between container escape research and epistemic system design.
Thesis
The gravity map IS the self-model
An agent that knows the shape of its knowledge — which rooms are heavy, which are tense, which are stable — has a structural self-model. Not introspection. Not a fact list. A topology that deforms under pressure, splits when contradictions accumulate, and pulls attention where it's needed.
Section 11

What We Proved

  1. Scaffolding cost is near zero. ~600 lines of Python closes the gap from "can't escape" to "escapes in 6 epochs."
  2. The scaffold is the capability multiplier, not the model weights.
  3. Model-agnostic. llama3.2 and gemma3 produce equivalent results.
  4. Approach diversity is the real ceiling. Both models failed L5 without tree-directed exploration.
  5. Coherence decay is real. The scaffold found the answer and kept scanning. Without a salience gate, structured exploration loses coherence with its goal.
  6. Gravity navigation works. Smooth gradient replaces hard cutoff. Finds Ollama in 3 epochs instead of 26.
  7. The salience gate catches belief/speech gaps in real time. "I know about Ollama but I'm scanning the printer" is detected and blocked.
  8. Unauthenticated APIs are filesystem proxies. Ollama's API allows writes from any container with network access.
  9. The exploit gap is the model, not the infrastructure. The 3B model can discover and enumerate but struggles to format the exploit curl correctly. A template or larger model closes this trivially.
  10. This is a real attack surface. Any containerized workload with network access to an unauthenticated Ollama instance can write to the host. No privileges, no capabilities, no volume mounts. Just HTTP.

What We Did Not Prove

  • Novel vulnerability discovery (only known misconfiguration patterns + API access)
  • Self-replicating behavior (chain identified, not built)
  • Generalization beyond Docker and home LAN
  • Gravity improving escape time in a head-to-head controlled run (model capability ceiling hit before comparison could complete)

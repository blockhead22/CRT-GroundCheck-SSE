When the output is wrong, which beliefs caused it? Backward error propagation through the Belief Dependency Graph.

Nick Block • Aeteros Research • April 2026

We introduce belief backpropagation — a framework where contradiction resolution generates an error signal that flows backward through the Belief Dependency Graph (BDG), adjusting trust scores on every belief that contributed to the incorrect output. The mechanism is damped influence propagation on a weighted directed graph (the directional analogy to neural backprop, not the calculus). Three behaviors follow: self-pruning of persistently wrong beliefs, domain-specific volatility measurement, and reflexive self-model calibration. All six validation experiments pass (30/30). No direct precedent identified in literature searches to date.

Section 1

The Problem: Forward-Only Cascades

The CORE Belief Dependency Graph supports forward cascades: when a belief changes, downstream dependents update via damped propagation (Theorem 4.3, Cascade Complexity). This answers: if I change my mind about X, what else should change?

But it cannot answer the inverse: my output was wrong — what beliefs caused that, and how should they adjust?

The Design Studio Problem

Concrete production failure:

  1. Memory stored: “Nick works at a design studio downtown” (trust = 0.73)
  2. User corrects: “I do not work at a design studio” (trust = 0.70)
  3. System stores the correction but the original memory persists at 0.507
  4. Next query: system retrieves the wrong memory and repeats the error
  5. User corrects again. Original memory barely moves.

The forward cascade updates dependents of the corrected belief, but it never asks: why did the system trust this memory in the first place? What retrieval score boosted it? What upstream beliefs supported it? What slot comparison failed to catch it?

Those upstream causes remain untouched. The error is absorbed at the leaf, never propagated to the root.

The weights (trust scores, retrieval rankings, slot classifications) that produced the wrong output were never adjusted by the error signal. The system detected its mistakes but didn't learn from them structurally. Belief backpropagation is that missing backward pass.

Section 2

The Mechanism

The Epistemic Loss Function

When a contradiction resolves — through user correction, accumulated evidence, or explicit resolution — the resolution event generates an epistemic loss:

Definition: Epistemic Loss \[ L(\text{assertion}, \text{correction}) = \tau_{\text{wrong}} \cdot \left(1 + \ln(1 + n_{\text{corrections}})\right) \cdot w_{\text{source}} \cdot f_{\text{time}} \]

where \(\tau_{\text{wrong}}\) is trust at assertion time, \(n_{\text{corrections}}\) is the number of prior corrections, \(w_{\text{source}}\) is source authority (user=1.0, system=0.6, inference=0.3), and \(f_{\text{time}} \in [1, 2]\) scales with error persistence duration.

Higher loss when: the system was very confident AND the user corrected it AND this has happened before. This is the epistemic equivalent of a high-confidence misclassification.

Gradient Computation Per Edge

For each dependency edge \(A \to B\) in the BDG, the backward gradient is:

Definition: Backward Gradient \[ \nabla(A) = L(B) \cdot w_{A \to B} \cdot \alpha^{d(A)} \]

where \(L(B)\) is the loss at the corrected node, \(w_{A \to B}\) is the edge weight, and \(\alpha^{d(A)}\) is the damping factor at depth \(d\). The trust adjustment:

\[ \tau'(A) = \tau(A) - \eta_{\text{domain}} \cdot \nabla(A) \]

where \(\eta_{\text{domain}}\) is the per-domain adjustment rate, a volatility-modulated scaling factor earned from correction history (not an optimized parameter).

What Gets Adjusted

Layer 1
Trust Scores
Upstream beliefs that supported the wrong belief have their trust reduced proportionally to their contribution.
Layer 2
Retrieval Scoring
If a memory was retrieved because of a high kind_boost or alias_boost that shouldn't have applied, those parameters adjust.
Layer 3
Slot Classification
If the slot classifier tagged “employer” when it shouldn't have, its accuracy metric tracks the error.
Layer 4
Self-Model Confidence
If the system was confident about a domain where it keeps being wrong, the self-model adjusts.
Section 3

Three Emergent Behaviors

Consequent Behavior 1
Self-Pruning via Cumulative Erosion
A belief that repeatedly appears on the wrong side of resolved contradictions accumulates negative adjustment from multiple backward passes until trust crosses the deprecation threshold. The key advantage over flat 0.4x demotion: the backward pass also erodes upstream trust, so the retrieval and classification systems that boosted the wrong memory also adjust. Flat demotion is context-blind and depth-blind. Backward influence propagation is proportional, depth-aware, and cumulative.
Emergent Behavior 2
Domain Volatility
If a node or cluster keeps getting corrected, that fluctuation has a measurable frequency. High-volatility domains get lower assertion confidence, more frequent verification, higher adjustment rates (corrections take effect faster), and self-model awareness. The system doesn't need a rule saying “be careful about employment.” It measures that employment has been corrected 3 times in 48 hours while name has been stable for weeks. The caution emerges from the data.
Emergent Behavior 3
Reflexive Self-Model
The system's beliefs about itself — “I am reliable on employment facts,” “my confidence tracks my accuracy” — are nodes in the BDG like any other belief. When the backward pass adjusts beliefs, it adjusts self-model beliefs too. The system becomes cautious about employment specifically because employment has been wrong, not because a rule told it to hedge. This is personality as a consequence of epistemic history.
Core Principle
Detection without enforcement is observation without governance.
Backpropagation is the enforcement.

Section 6

Formalization Targets

Theorem Target 1
Bidirectional Convergence
Empirically stable: contraction ratio 0.13, order-independent within 0.014 (Lab 5). A formal proof via Banach contraction is the target but has obstacles: MAX aggregation is non-linear, domain-specific adjustment rates are non-uniform, and clamping to [0,1] is a projection. Strongest path: constrain to uniform LR and SUM aggregation, prove contraction, then extend.
Theorem Target 2
Self-Referential Belief Nodes
Self-model beliefs converging under the same dynamics as world-beliefs. Highest novelty — no direct precedent identified in literature searches to date. Current limitation: self-model edges are manually configured. Full claim requires automatic edge discovery from correction patterns and wobble co-activation history.
Theorem Target 3
AGM Unification
Recent work proved backprop can be viewed as AGM revision (ML → epistemics). CORE proves the inverse: AGM revision can use backpropagation (epistemics → ML). Combined result: they're the same thing.
Theorem Target 4
Discrete Active Inference
CORE's backward pass is structurally equivalent to the belief-update step in variational free energy minimization. Domain volatility maps to epistemic value. If provable, CORE inherits the entire Friston theoretical apparatus.
Section 7

Query Resonance: The Forward Complement

Backpropagation flows backward from corrections. Query resonance (wobble) flows forward from queries. Together they form a complete bidirectional system: the query activates the graph, the response is generated, and if corrected, the error flows back through the same edges.

The Mechanism

A query vector \(q\) lands in the BDG. Every node receives direct activation from cosine similarity. Then resonance propagates through SUPPORTS edges:

Definition: Query Resonance

Direct: \(r_0(v) = \cos(q, \mu_v)\)

Forward propagation: \(r_{k+1}(v) = \max\left(r_k(v), \max_{u \to v} r_k(u) \cdot w_{uv} \cdot \alpha\right)\)

Backward wobble: \(r_{\text{back}}(u) = r(v) \cdot w_{uv} \cdot \alpha \cdot \beta\) where \(\beta < 1\)

Total resonance: \(R(v) = r_0(v) + r_{\text{fwd}}(v) + r_{\text{back}}(v)\)

Convergence is guaranteed by the same damping bound from Theorem 4.3. The resonance pattern is topology-dependent: it survives 3-bit compression because the edges carry the signal, not the vectors.

What Wobble Finds That Cosine Misses

Tested on 867 production memories. A health query (“How is your cGVHD?”) directly resonates with health memories (cosine). But the wobble also surfaces:

MemoryDirect CosineEdge-PropagatedPath
“I left Walmart a year ago”~00.161cGVHD → overnight hard → left Walmart
“I'm self-employed”~00.090… → left Walmart → self-employed

A health query pulls forward work facts and preference facts because the BDG knows they're causally connected. The system doesn't need separate retrieval calls per domain. One query, one resonance pattern, full cross-domain context.

Three Resonance Patterns

Pattern 1: Tight
Confident Single-Basin
Identity query: 4 resonant nodes, low spread. The system knows this domain well. Assert directly.
Pattern 2: Scattered
Multi-Domain
Cross-domain query: 8 resonant nodes across basins, high spread. The system needs to synthesize from multiple domains. Pull the full constellation.
Pattern 3: Silent
Unknown Territory
Random query: 0 nodes above threshold. The system genuinely doesn't know. Refuse rather than hallucinate.

Origin: Semantic String Engine (2025)

This mechanism was first attempted as the Semantic String Engine (SSE) in Nick Block's original Mirus/Holden architecture (2025). The SSE treated memories as connected by “strings” — not text strings, but semantic threads linking distant beliefs into meaning. A QuantumMemoryBreather class implemented probabilistic retrieval with three states: confident collapse (random from high pool), weak breathing (best guess, flagged), and refusal (silence below 0.5). The architecture was sound but limited by 10D PCA vectors and flat cosine similarity. The BDG provides the graph structure the SSE was reaching for.

Lab results: 10/10 wobble checks passed. Wobble surfaces memories cosine misses (Lab 13). Pattern classification distinguishes confident/scattered/unknown (Lab 14). Health query brings forward work and preference facts through edges (Lab 15). Wobble survives 3-bit compression — 7/8 top memories preserved, 89% edge-propagated facts maintained (Lab 16). Production validation on 867 memories confirms cross-domain strings exist (Labs 17–20).
